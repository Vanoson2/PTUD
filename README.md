# Travel Accommodation Booking Platform

A web-based accommodation booking platform developed using PHP and MySQL.
The system supports three main user roles: Traveller, Host, and Administrator.

## Project Overview

The project was developed as a team-based academic project.
It focuses on requirements analysis, database design, role-based access,
booking workflows, property management, and system testing.

## Main Features

### Traveller
- Register, log in, and manage personal information
- Search and view accommodation listings
- Book and cancel accommodation
- View booking history
- Submit reviews

### Host
- Create and manage accommodation listings
- Manage booking requests
- Monitor listing status
- View reports and revenue information

### Administrator
- Manage users and host registrations
- Manage listings, services, and amenities
- Monitor reports and system activities

## System Architecture

The application follows an MVC-based structure:

- `controller/`: Handles application logic and user requests
- `model/`: Handles business logic and database operations
- `view/`: Contains user interface components
- `database/`: Contains database scripts
- `public/`: Contains public assets
